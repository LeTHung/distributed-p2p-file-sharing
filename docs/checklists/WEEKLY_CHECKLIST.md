# Checklist họp tuần

## Trước họp

- [ ] Mỗi người cập nhật issue: đã làm, đang làm, blocker.
- [ ] Code liên quan đã commit hoặc có link branch/PR.
- [ ] Có log hoặc ảnh chứng minh mốc kỹ thuật tuần.

## Trong họp

- [ ] Chạy bản tích hợp mới nhất từ `main`.
- [ ] So đối chiếu mốc tuần trong `WORK_PLAN.md`.
- [ ] Ghi người phụ trách và hạn cho blocker.
- [ ] Chốt issue tuần kế tiếp, không nhận thêm scope chưa cần thiết.

## Sau họp

- [ ] Cập nhật Google Docs/Drive với quyết định và link PR.
- [ ] Đóng các issue đã đạt điều kiện hoàn thành.
- [ ] Đưa các lỗi còn lại sang issue riêng có người chịu trách nhiệm.
