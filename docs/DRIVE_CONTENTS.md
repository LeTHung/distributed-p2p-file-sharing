# Nội dung Drive nhóm

Drive là nơi lưu các tài liệu có thể cập nhật chung và file demo. GitHub là nguồn chính cho code và mọi tài liệu kỹ thuật có version.

## Cấu trúc Drive đề xuất

```text
HTPT - Nhóm 6/
  01 - Quản lý nhóm/
    Kế hoạch & phân công BitTorrent-Lite (Google Docs)
    Biên bản họp tuần
  02 - Demo/
    input/             # file nguồn, không commit file lớn vào GitHub
    output/            # file ghép và log/hash minh chứng
    video/             # video demo
  03 - Báo cáo & slide/
```

## Nội dung tài liệu “Kế hoạch & phân công BitTorrent-Lite”

Sao chép nguyên vẹn các phần sau từ GitHub khi tạo Google Docs: `PROJECT_CHARTER.md`, `TEAM_RULES.md`, `WORK_PLAN.md` và `DEMO_AND_TEST_PLAN.md`. Mỗi tuần thêm vào cuối Docs: việc đã hoàn thành, link PR/commit, lỗi đang chặn và việc kế tiếp.

Không đưa password database, file `.env`, token GitHub hay token Drive vào Drive hoặc GitHub.
